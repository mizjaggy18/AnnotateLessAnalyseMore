Section 1

Installation & Launch

Option A — Standalone Executable (recommended)

The executable version requires no Python installation on the target machine. One build step on any Windows PC with Python 3.9+ is sufficient to produce a self-contained .exe.

  1. Open a terminal in the AnnotateLessAnalyseMore Installation_v2 folder and double-click build.bat.
  2. The script creates a virtual environment, installs all dependencies, and runs PyInstaller. This takes 2–5 minutes on first run.
  3. When complete, locate dist\AnnotateLessAnalyseMore.exe.
  4. Copy only the .exe to any folder that contains your image files.
  5. Double-click AnnotateLessAnalyseMore.exe. A terminal window opens and your browser navigates to http://127.0.0.1:5000 automatically after ~3 seconds.
  6. Close the terminal window to stop the server.
After build.bat completes, the installation folder will look like this:
AnnotateLessAnalyseMore Installation_v2\ ├── app.py ├── annotate.spec ├── build.bat / run.bat / run.sh ├── requirements.txt ├── README.md & UserManual.html ├── static\ templates\ ├── venv\ ← Python environment (~500 MB) ├── build\ ← intermediate cache (safe to delete) └── dist\ └── AnnotateLessAnalyseMore.exe ← ~80–120 MB

Option B — Run from Source

Requires Python 3.9+ on the machine running the app. No separate build step.

OSCommand
Windowsrun.bat — double-click or run in terminal
macOS / Linuxchmod +x run.sh && ./run.sh

Both scripts auto-create a venv/ on first run, install requirements.txt, and start the Flask server. Open http://127.0.0.1:5000 in your browser.

Manual Setup

python -m venv venv
venv\Scripts\activate      # Windows
source venv/bin/activate   # macOS / Linux
pip install -r requirements.txt
python app.py

The interface is divided into three vertical panels. The title bar runs across the top.

Section 3

Image Files

Place image files in the same folder as AnnotateLessAnalyseMore.exe (standalone mode) or in the project root (source mode). The application auto-discovers all supported formats on startup.

Supported formatsNotes
.jpg / .jpegStandard JPEG (most common for TCGA tiles)
.pngPNG — also used for masks; mask files are excluded from the image list automatically
.tif / .tiffTIFF (uncompressed or LZW)

Files whose names contain _inst_map, _sem_map, or begin with mask_ are treated as masks and appear only in the Load Mask dialog, not in the image list.

Click any image name in the left sidebar to load it. Unsaved annotations for the current image are automatically saved before switching.

Section 4

Label Configuration

The label setup dialog appears on first launch. It pre-fills with the CoNSeP / PanNuke nuclear classification schema. You can customise labels at any time.

IndexLabelColour
0Background#ffffff
1Neoplastic#ff0000
2Inflammatory#0000ff
3Connective#00ff00
4Dead#808080
5Epithelial#ffff00

Changing Labels

  1. Click ⚙ Labels in the toolbar (top right).
  2. Adjust the number of labels, change names and colours, or drag the ⠿ handle to reorder rows.
  3. Click Use Previous Labels to restore the last saved set.
  4. Click Start Annotating → to apply.
Label persistence: Your configured label set is saved in browser localStorage and restored automatically on next visit. Class indices 0–5 are fixed to the CoNSeP convention for PNG export compatibility; user-added labels receive indices starting at 6.

The Labels Panel (right sidebar)

The Labels panel shows each class with a colour swatch, name, and a live count of annotations currently carrying that label. The count updates immediately after every annotation change.

Section 5

Drawing Tools

Select the active drawing tool from the toolbar or using keyboard shortcuts. The active label determines the class assigned to every new annotation.

5.1  Polygon Draw  D

Click on the canvas to place vertices one at a time. A preview line follows the cursor.

  • Close the polygon — click near the first vertex (snap circle appears), or double-click anywhere, or right-click.
  • Cancel — press Esc. The partial polygon is discarded.
  • A minimum of 3 vertices is required before closing.

5.2  Freehand Draw  H

Click and drag to draw a free-form stroke. The path is recorded in real time.

  • Finish — release the mouse / lift the stylus. The stroke is automatically simplified using the Ramer–Douglas–Peucker algorithm to reduce vertex count.
  • Cancel mid-stroke — right-click or press Esc.
  • If the stroke is too short (fewer than 3 points after simplification), it is discarded and the annotation under the cursor is selected instead.

5.3  Edit Tool  E

Click an annotation to select it. Selected annotations are highlighted on the canvas and in the annotation list.

  • Move a vertex — drag any vertex handle.
  • Insert a vertex — click on any polygon edge; a new vertex is inserted at that point.
  • Relabel — with one or more annotations selected, change the label selector in the toolbar; all selected annotations are relabelled at once.
  • Delete — press Del or Backspace.

5.4  Pan  P or hold Space

Pan mode disables annotation interaction. Drag the canvas to scroll the view. Equivalent to scrolling (vertical pan) or two-finger swipe on a touchpad.

Section 6

Stylus & Touch Input

All tools are built on the Pointer Events API and work with mouse, touch, and pen/stylus inputs without configuration.

InputBehaviour
Single finger / touchAlways pans the canvas, regardless of active tool
Two-finger pinchZoom and pan simultaneously
Stylus tip (draw mode)Draws as normal polygon or freehand
Stylus tip (freehand mode)Stroke is captured with setPointerCapture — no interruption even if the tip leaves the canvas edge
Stylus tip (polygon draw)Automatically switches to freehand on a drag stroke; short taps select the annotation under the tip
Stylus barrel button (edit mode)Press and drag to draw a freehand stroke; on release the annotation is created, the tool stays in edit mode, and the new annotation is auto-selected
Short barrel tap (edit mode)Selects the annotation under the stylus tip
Barrel button note: Some OS/driver combinations fire a contextmenu event when the barrel button is pressed. The app suppresses this event during an active barrel-button freehand stroke to prevent accidental cancellation.
Section 7

Annotation Management

Selection

  • Single select — click an annotation on the canvas (edit tool) or click its row in the annotation list.
  • Multi-select (toggle) — Ctrl + click to add or remove an annotation from the selection.
  • Range select — Shift + click in the annotation list to select all annotations between the last clicked and the current row.
  • Rubber-band select — in edit mode, drag on empty canvas to draw a selection rectangle. Any annotation with at least one vertex inside the rectangle is selected. Hold Ctrl while dragging to add to the existing selection.
  • Keyboard navigation — ↑ / ↓ moves through the annotation list (when no text input has focus).

Deleting Annotations

  • Select one or more annotations, then press Del or Backspace.
  • Click the ✕ Delete button in the toolbar to delete all currently selected annotations.
  • Click ✕ All in the annotation panel header to delete all annotations for the current image (requires confirmation). This action is undoable.

Relabelling

  • Select one or more annotations, then change the label in the toolbar label selector — all selected annotations are relabelled at once.
  • Alternatively, use the inline dropdown in each annotation's list row to relabel that annotation individually.

Undo / Redo

  • Ctrl + Z undoes the last annotation action (up to 50 steps).
  • Ctrl + Y redoes. Any new action clears the redo stack.

Discard Changes

The ✕ Discard button (enabled only when there are unsaved changes) reverts all edits to the last saved state. An orange dot in the status bar indicates unsaved changes.

Overlay & Outline Opacity

Two independent visibility controls are in the toolbar:

  • Overlay checkbox + slider — controls the filled polygon opacity (0–100%). Default 18%.
  • Outline checkbox + slider — controls the polygon border opacity (0–100%). Default 100%.

Selected annotations receive 2.5× the base overlay opacity and a thicker stroke (2.5 px vs 1.5 px) for visibility regardless of slider values.

Annotation ID Labels

  • Each annotation is assigned a sequential number (1…N) drawn at its centroid.
  • IDs checkbox in the toolbar toggles these labels on and off.
  • The adjacent slider adjusts the font size from 8 to 32 px.
  • The same number appears in the annotation list row for cross-reference.

Dark / Light Mode

Click Light Mode / Dark Mode in the title bar to toggle the theme. The canvas checkerboard adapts to the theme. The preference is saved in browser localStorage and restored on next visit.

Section 9

Saving Annotations

Annotations are stored as JSON files in an annotations/ sub-folder next to the application (created automatically on first save).

  • Manual save — click 💾 Save in the toolbar or press Ctrl + S.
  • Auto-save — annotations for the current image are saved automatically when you switch to a different image.
  • The orange dot in the status bar indicates unsaved changes.
File location: annotations\<image_filename>.json (e.g. annotations\slide01.jpg.json). These files are plain JSON and can be inspected or version-controlled.
Section 10

Loading Masks

Click ⬇ Load Mask in the toolbar to import an existing PNG mask as editable annotations. The dialog runs in two steps.

Step 1 — Select a Mask File

The dropdown lists all mask files found alongside the images. The app auto-suggests the mask that matches the current image name (e.g. slide01_inst_map.png for slide01.jpg).

Step 2 — Confirm Label Assignment

The app analyses the mask and shows a summary. Three mask types are handled:

Mask typeDetectionResult
Semantic map (_sem_map.png) Filename suffix or pixel values 1–5 matching class indices Each pixel value is mapped to the corresponding CoNSeP label. Include / Skip checkboxes per class.
Instance + semantic pair (_inst_map.png + _sem_map.png) Instance map filename with paired semantic map present Each instance is labelled by the most frequent class in the semantic mask at that instance's pixels. Per-class instance counts are shown for confirmation.
Instance only (_inst_map.png) Instance map filename, no paired semantic map All instances receive the same fallback label (user selects).

The Max polygons field (default 10 000, maximum 50 000) limits how many annotations are imported. Adjust downward for faster loading on large masks.

Click Import to convert the mask to individual polygon annotations. The new annotations are added to any existing annotations for that image.

Type detection priority: Filename suffixes (_inst_map / _sem_map) always take precedence over pixel-value heuristics. This prevents instance maps with ≤ 5 annotations being misidentified as semantic class maps.
Section 11

Exporting

Export buttons appear in the toolbar. Annotations must be saved before exporting.

Export PNG Masks

Click Export PNG. Two mask files are written to the same folder as the source image:

FileBit depthPixel value
<stem>_sem_map.png uint8 Class index 0–5 (CoNSeP convention). Background = 0.
<stem>_inst_map.png uint16 Sequential instance ID 1…N (annotation order). Background = 0.

<stem> is the image filename without its extension (e.g. slide01.jpg → slide01_sem_map.png).

These files are directly compatible with CoNSeP ground-truth format and can be reloaded via the Load Mask dialog.

Export GeoJSON

Click Export GeoJSON. A <stem>.geojson file is written to the image folder. The file is a standard GeoJSON FeatureCollection compatible with QuPath 0.4+:

  • Each annotation is a Polygon feature with objectType: "annotation".
  • classification.name — the label name.
  • classification.color — an [R, G, B] array (QuPath 0.4+ format).

To import into QuPath: File → Import Objects → From GeoJSON/Feature Collection.
